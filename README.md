# Exercícios de JavaScript

Repositório onde guardo os exercícios que faço enquanto estudo JavaScript.

Por enquanto, estou praticando principalmente:

- Variáveis e entrada de dados;
- Operadores;
- Condições (`if` e `else`);
- Comparações e cálculos.

### Como executar

Os exercícios podem ser executados com Node.js. Alguns utilizam a biblioteca `prompt-sync`, que pode ser instalada com:

```bash
npm install prompt-sync
```

Para executar um arquivo:

```bash
node nome-do-arquivo.js
```
