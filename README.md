# 📘 Exercícios de JavaScript

Repositório dedicado às atividades e exercícios que desenvolvo durante meus estudos de **JavaScript**, com foco na construção da lógica de programação e na prática dos fundamentos da linguagem.

## 🎯 Objetivo

Praticar programação por meio de pequenos problemas, desenvolver o raciocínio lógico e acompanhar minha evolução como estudante de Engenharia de Software.

## 📚 Conteúdos praticados

As atividades registradas incluem conceitos como:

- Entrada e saída de dados pelo terminal;
- Variáveis e conversão de valores;
- Operadores aritméticos e relacionais;
- Estruturas condicionais (`if` e `else`);
- Comparação e classificação de números;
- Cálculos e operações com valores.

> Os conteúdos podem aumentar conforme novos exercícios forem adicionados ao repositório.

## ▶️ Como executar

1. Instale o [Node.js](https://nodejs.org/).
2. Clone este repositório ou baixe os arquivos.
3. Abra a pasta do projeto no terminal.
4. Nos exercícios que utilizam `prompt-sync`, instale a dependência:

   ```bash
   npm install prompt-sync
   ```

5. Execute o arquivo desejado:

   ```bash
   node nome-do-arquivo.js
   ```

## 📁 Organização

Os exercícios são armazenados em arquivos JavaScript individuais, permitindo executar e consultar cada atividade separadamente.

## 🚀 Evolução

Este repositório é atualizado conforme avanço nos estudos. Novas atividades e conceitos serão adicionados gradualmente.
